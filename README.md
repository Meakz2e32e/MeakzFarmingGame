# Farming Game

**Made by Meakz**

A small Python farming game I'm working on to improve my coding.

You can farm crops, check your stats, sell your harvest and build up your cash.

honestly kinda basic but looking to improve with tkinter or pygame so enjoy the prototype i guess or take the idea feel free!

## Requirements for this script
- Python
- Pygame

## How to Run
1. Install Python.
2. Install Pygame using `pip install pygame`.
3. Make sure `FarmStartUp.wav` is in the same folder as the Python script.
4. Run the script.
